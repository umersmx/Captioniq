Engineering Highlights

Built for Performance & Compatibility

Why Captioniq exports outshine conventional screen-record and cloud burners.

Deterministic 60 FPS Engine

Conventional tools record canvas streams at 1x real-time, dropping frames on high-load passes. Captioniq seeks exact frame timestamps mathematically, encoding every single frame with zero drops.

Native WhatsApp Compatibility

Streaming canvas recorders produce Fragmented MP4 files (moof chunks) that WhatsApp rejects as corrupted. Captioniq muxes strict FastStart ISO MP4 containers with front-loaded moov headers for immediate playback.

Automatic Speech-to-Text

Generate timestamped subtitle cues straight from audio speech. Choose between 100% private in-browser WebAssembly models or lightning-fast Neural Speech AI transcription with instant language detection.

Hindi & Roman Hindish Script

Native transliteration support for South Asian creators. Switch seamlessly between authentic Devanagari Hindi script and modern Roman Hindish letters (English phonetic spelling) with a single click.

1:1 Viewport Alignment Matching

Subtitles rendered on canvas use proportional scale factors referenced against the preview monitor. 50% vertical and 50% horizontal positioning lands dead-center on export, matching your editor view exactly.

100% Client-Side Privacy

Your video never leaves your browser memory. No cloud rendering queue, no file size limits, no watermark branding, and no personal account registration required.

Frequently Asked Questions

Everything You Need to Know

Clear answers to technical details, file formats, and device compatibility.

Most browser-based export tools use native MediaRecorder, which outputs fragmented streaming MP4 files (moof chunks) without a top-level moov duration header. WhatsApp's security scanner flags these fragmented streams as potentially corrupted. Captioniq muxes clean, standard FastStart ISO MP4 containers with the moov atom placed directly at the front of the file, allowing instant, native playback on WhatsApp, iOS, Android, and QuickTime.

Unlike real-time screen capture tools that record while the video plays (dropping frames whenever CPU or GPU load spikes), Captioniq utilizes hardware-accelerated WebCodecs. It pauses playback, deterministically seeks to exact frame mathematical timestamps (frameIndex / fps), draws the subtitle overlay onto canvas, and feeds the exact raw VideoFrame into the hardware encoder. The resulting video has a rock-solid, constant frame rate at 30 or 60 FPS.

Hindi (Devanagari) uses the traditional Indian script (e.g., "आप कैसे हैं"), while Hindish (also known as Hinglish or Roman Hindi) writes spoken Hindi words using English Latin letters (e.g., "Aap kaise hain"). Captioniq includes a native transliteration toggle so creators can target social media audiences who prefer reading casual Roman English captions.
